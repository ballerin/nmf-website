# Welcome! 👋

This is the documentation for the **Norsk Matematisk Forening** website.

## What is this?

The NMF website is a collection of pages about the society — news, events, the INFOMAT magazine, board members, prizes, and more. The site lives on the internet at **[nmf-website.pages.dev](https://nmf-website.pages.dev)** and is built from simple text files stored on GitHub.

## Do I need to be a programmer?

**No.** If you can write an email, you can edit this website.

There are two ways to make changes:

| Method | Best for | Difficulty |
|---|---|---|
| **CMS** (browser editor) | Adding news, events, INFOMAT issues | 🟢 Easy — point and click |
| **GitHub web editor** | Editing navigation, board members, carousel | 🟡 Medium — edit text carefully |

The browser-based CMS gives you a form to fill out. You don't see any code. You don't need to install anything. It works on Windows, Mac, and Linux.
